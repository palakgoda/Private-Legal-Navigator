# Design System: Private Legal Navigator

## Visual Direction
Warm neutral background `#F7F8FA`, surface `#FFFFFF`, ink `#172033`, muted `#596579`, primary `#1E4D8F`, primary-dark `#163A6C`, success `#176B4D`, warning `#8A5A00`, danger `#A33A3A`, border `#D7DDE7`.

## Core Principles
1. **Explain before advising**: Clear, stepwise presentation that reduces cognitive overwhelm.
2. **Private by default**: Explicit shield banner and local processing verification before file intake.
3. **Honest uncertainty**: Explicit "Needs verification", "Unclear from document", and "Not legally determinable by software".
4. **Zero-Pill Discipline**: Clean unboxed metadata separated by typographic dividers (`·`), functional filter buttons rather than candy badges.
5. **Top Bar Contract**: Exactly 3 zones: Brand title, nav links, primary action (Quick Exit & Delete Session).
6. **Print & Accessibility**: Print-ready clean typography omitting sensitive data; full keyboard navigation.
